# Переход на восстановленную Sfery

1. Закройте обычную Sfery.
2. Распакуйте архив обновления в отдельную папку.
3. Запустите Update-Sfery.cmd рядом с Sfery_1.45.0_x64-setup.exe. Он включает режим обновления `/UPDATE`, сохраняющий путь существующей установки.
4. Откройте Sfery привычным ярлыком. При первом запуске создаётся проверенная резервная копия прежней базы и вложений.

Удалять старую Sfery и её папку данных перед обновлением не нужно. Задачи, сферы, проекты, корзина и вложения остаются в прежней папке. Для Telegram потребуется повторный вход. До подключения реальных аккаунтов новая сборка должна пройти проверку владельцем приложения.

Переход с 1.44.0 выполняется вручную один раз: прежний ключ автообновлений недоступен. Версия 1.45.0 использует новый ключ и отдельный канал для следующих обновлений.
