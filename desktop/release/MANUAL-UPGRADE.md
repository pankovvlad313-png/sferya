# Sfery 1.0.0 Beta — обновление (техническая версия 1.45.1)

1. Закройте обычную Sfery.
2. Распакуйте архив обновления в отдельную папку.
3. Запустите Update-Sfery.cmd рядом с Sfery_1.45.1_x64-setup.exe. Он включает режим обновления `/UPDATE`, сохраняющий путь существующей установки.
4. Откройте Sfery привычным ярлыком. При первом запуске создаётся проверенная резервная копия прежней базы и вложений.

Удалять старую Sfery и её папку данных перед обновлением не нужно. Задачи, сферы, проекты, корзина и вложения остаются в прежней папке. Подключение Telegram из 1.45.0 сохраняется; переподключать аккаунт для патча не требуется.

Из 1.45.0 доступно обычное автообновление. Переход с 1.44.0 выполняется вручную один раз: прежний ключ автообновлений недоступен. Выпуски начиная с 1.45.0 используют новый ключ и отдельный канал. При переходе с 1.44 Telegram может потребовать повторный вход.

Имя выпуска в интерфейсе — «1.0.0 Beta». Для корректного автообновления используется возрастающий технический номер 1.45.1.

После обновления выберите человека в Telegram и получите новое входящее поручение. Найденные сообщения появляются во «Входящих» для подтверждения кнопкой «Создать задачу». Сообщения, уже пропущенные прежним распознаванием, автоматически не перечитываются. Живое получение на личном аккаунте не входило в автоматические проверки.

Установщик и EXE не имеют подписи Windows Authenticode. Подпись обновления Tauri проверяет подлинность патча, но не заменяет подпись Windows.
