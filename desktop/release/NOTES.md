# Sfery 1.0.0 Beta

Патч Telegram. Техническая версия **1.45.1**, чтобы пользователи 1.45.0 могли обновиться обычным способом.

- Личные чаты показывают имя, фамилию и @username. Поиск работает и по фамилии, и по username; боты и «Избранное» различаются по типу.
- Исправлено чтение новых сообщений после выбора чата. Очередь сообщений обрабатывается по порядку и не теряется при большом количестве сообщений.
- Расширено распознавание просьб, включая «Купи хлеб», «Посмотри документ», «Скинешь отчёт?» и «Нужен отчёт».
- Повторный выбор чата не пропускает непрочитанные сообщения. Исходящие сообщения не становятся поручениями; дубликаты не создаются.

Сферик, его анимации и дизайн страниц сохранены. Локальные данные и Telegram-сессия 1.45.0 остаются на месте. Найденное появляется во «Входящих» для подтверждения; сообщения, уже пропущенные старым классификатором, автоматически не перечитываются.

Из 1.45.0 доступно автообновление; для 1.44 нужен архив ручного перехода. Старый канал `latest.json` сохранён без изменений.

Ограничения: живое получение поручений на личном аккаунте не проверено; EXE и установщик пока не имеют подписи Windows Authenticode. Обновление подписано ключом Tauri, который используется с 1.45.0.
